# myRAG

**一句话**：给业务产品（首先是合同审查 Agent-T）用的**可选**知识与检索底座——先翻资料、再生成，并尽量带出处。

## 它不是什么

- 不是 Agent-T 的替代品（审查结论仍由清单规则门禁）  
- 不是「必须一开始就上」的依赖：单份合同审查可以没有 myRAG  

## 它是什么

类比：**化验设备**。Agent-T 是体检报告；基础问诊可以不做化验，深度体检（模板对照、法规引用、多文档项目）再接。

对外目标能力（薄接口，实现可换）：

```text
retrieve(query, scope) → 带出处的原文片段
```
